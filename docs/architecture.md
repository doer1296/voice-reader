# Voice Reader 架构说明

> 理解系统设计、模块职责及数据流

## 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    AI 助手 / 外部调用方                          │
│  (写入待朗读内容到 pending.txt)                                  │
└──────────────────────┬──────────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────────┐
│                     ┌───────────────────────┐                    │
│                     │     pending.txt       │ ◄── 共享文件      │
│                     │  (全局共享文件)       │                    │
│                     └───────────┬───────────┘                    │
│                                 │                                │
│                    ┌────────────▼────────────┐                   │
│                    │  voice-watcher.mjs      │                   │
│                    │  (常驻监听器)            │                   │
│                    │  轮询检测 → 读取 → 朗读  │                   │
│                    └────────────┬────────────┘                   │
│                                 │                                │
│                    ┌────────────▼────────────┐                   │
│                    │  voice-reader.mjs       │                   │
│                    │  (单次朗读引擎)          │                   │
│                    │  CLI 调用 → 直接朗读     │                   │
│                    └────────────┬────────────┘                   │
│                                 │                                │
│                    ┌────────────▼────────────┐                   │
│                    │  Windows SAPI SpVoice   │                   │
│                    │  (COM 对象，系统原生)    │                   │
│                    │  朗读 + System.Beep 音效 │                   │
│                    └─────────────────────────┘                   │
│                                                                  │
│   数据目录: %VOICE_READER_HOME% (%USERPROFILE%\.voice-reader)   │
└─────────────────────────────────────────────────────────────────┘
```

## 模块职责

### lib.js — 公共模块

纯函数工具库，不涉及 IO 副作用（路径检测除外）。提供：

| 导出 | 类型 | 说明 |
|------|------|------|
| `HOME` | 常量 | 数据目录，自动检测 |
| `PENDING` | 常量 | 共享文件路径 |
| `CONTROL` | 常量 | 控制信号文件路径 |
| `CONFIG_PATH` | 常量 | 配置文件路径 |
| `PS_PATH` | 常量 | PowerShell 路径 |
| `SPEAK_RATE` | 常量 | 朗读速率 |
| `SPEAK_VOLUME` | 常量 | 音量 |
| `SPEAK_VOICE` | 常量 | 语音引擎名称 |
| `POLL_INTERVAL` | 常量 | 轮询间隔 |
| `MAX_LENGTH` | 常量 | 截断字数 |
| `BEEP` | 对象 | 四种提示音定义 |
| `beepCmd()` | 函数 | 提示音 → PowerShell 命令 |
| `extractReadable()` | 函数 | 解析 pending.txt |
| `cleanText()` | 函数 | 文本清洗 |
| `getStatus()` | 函数 | 系统状态信息 |

### voice-watcher.mjs — 常驻监听器

持续运行的后台进程，核心循环：

```
每隔 POLL_INTERVAL 毫秒 ──→ 检测 pending.txt 是否有变化
                              │
                              ├── 有变化 → 提取内容 → 清洗 → 朗读 → 清空文件
                              │
                              └── 无变化 → 继续等待
```

支持控制信号：
- `stop.flag` 文件写入 `STOP` → 停止监听器
- `stop.flag` 文件写入 `PAUSE` → 暂停监听（保留进程）

### voice-reader.mjs — 单次朗读引擎

CLI 工具，支持多种命令模式：

| 模式 | 触发条件 | 行为 |
|------|----------|------|
| 朗读文本 | 传入参数 | 直接朗读参数内容 |
| 朗读文件 | 无参数 | 读取 pending.txt 朗读 |
| 停止 | `--stop` | 写入 STOP 信号 |
| 暂停 | `--pause` | 写入 PAUSE 信号 |
| 恢复 | `--resume` | 写入 RESUME 信号 |
| 状态 | `--status` | 输出系统状态 |
| 帮助 | `--help` | 输出完整帮助 |

## 数据流

### 文件写入 → 朗读

```
1. 外部程序写入 pending.txt
   └─ 格式: [VOICE_READER_START:type] 内容 [VOICE_READER_END]
   
2. 监听器检测到文件变化
   └─ extractReadable() 解析类型和内容
   
3. cleanText() 清洗文本
   └─ 去除 Markdown / 代码 / URL / 表格等
   
4. 生成 PowerShell 脚本
   └─ 提示音 Beep 命令 + SAPI 朗读命令
   
5. 执行脚本
   └─ Node.js 通过 child_process.spawn 异步执行
```

### 配置加载优先级

```
环境变量（最高优先级）
    ↓
config.json 文件
    ↓
代码默认值（最低优先级）
```

## 路径检测机制

`detectHome()` 函数按以下优先级确定数据目录：

```
1. 环境变量 VOICE_READER_HOME
2. 当前工作目录下的 .voice-reader/
3. %USERPROFILE%\.voice-reader/（默认）
```

---

## 文本清洗流水线

输入文本按以下顺序处理：

```
原始文本
    │
    ├── 去除代码块 ```...```
    ├── 去除行内代码 `...`
    ├── 去除加粗/斜体 ***...*** **...** *...*
    ├── 去除标题 # ...
    ├── 去除链接 [text](url) → 保留 text
    ├── 去除图片 ![alt](url) → 保留 alt
    ├── 去除 URL https://...
    ├── 去除引用块 > ...
    ├── 去除无序列表 - * +
    ├── 去除有序列表 1. 2.
    ├── 去除任务列表 - [x] ...
    ├── 简化表格行 | ... | → 空格连接
    ├── 合并多余空行
    └── 截断（超过 MAX_LENGTH 字）
    │
    ▼
纯净文本（可朗读）
```

## 提示音系统

四种提示音基于 `System.Console.Beep(frequency, duration)` 实现：

| 类型 | 起始音效 | 心理学效果 |
|------|---------|-----------|
| info | 800→1200Hz 升调 | 温和、中性、吸引注意 |
| success | 600→800→1200Hz 三阶升 | 向上、积极、成就感 |
| error | 1000→600→400Hz 三阶降 | 向下、消极、警示 |
| warning | 800→500Hz 双音 | 急促、紧迫感 |

## 技术栈

| 层次 | 技术 | 版本要求 |
|------|------|----------|
| 运行时 | Node.js | ≥ 18 (ESM) |

## 安全设计

- **无网络请求**：所有操作在本地完成，不发送任何数据到外部
- **无第三方依赖**：零 npm 依赖，无供应链风险
- **临时文件清理**：生成的 PowerShell 脚本 30 秒后自动删除
- **路径隔离**：数据目录独立，不影响系统其他部分
