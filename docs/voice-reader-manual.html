概述

Trae Voice Reader 是基于 Windows SAPI 的语音朗读系统，实现 AI 回复的自动语音朗读。支持四种差异化提示音（info / success / error / warning），让用户通过声音区分内容类型。

核心特性

  • SAPI 原生引擎，多音字朗读准确（储蓄 chǔ xù、银行 yín háng 等）
  • AI 自动朗读用户输入和回复内容
  • 四种差异化提示音，声音区分内容类型
  • 全局共享文件机制，所有任务可跨 workspace 调用
  • 极低资源占用（watcher 仅 37 MB，CPU 接近 0%）

调用方式

4.1 Skill 自动调用（推荐）

新建任务，输入：

Use Skill: voice-reader

AI 自动执行三步：

第 0 步：确保监听器运行

$r = Get-CimInstance Win32_Process -Filter "Name='node.exe'" | Where-Object { $_.CommandLine -like '*voice-watcher.mjs*' }
if (-not $r) {
    Start-Process -WindowStyle Hidden node -ArgumentList "C:\Users\15390\.trae-cn\work\.voice-reader\voice-watcher.mjs"
    Write-Host "监听器已启动"
} else {
    Write-Host "监听器已在运行"
}

第 1 步：朗读用户输入（先清空再写入）

$f = "C:\Users\15390\.trae-cn\work\.voice-reader\pending.txt"
[System.IO.File]::WriteAllText($f, "", [System.Text.Encoding]::UTF8)
$c = @"
[VOICE_READER_START:info]
用户说：XXX
[VOICE_READER_END]
"@
[System.IO.File]::WriteAllText($f, $c, [System.Text.Encoding]::UTF8)

第 2 步：朗读回复内容（直接写入）

$c = @"
[VOICE_READER_START:info]
回复内容（2-3 句，不超过 100 字，只说结论）
[VOICE_READER_END]
"@
[System.IO.File]::WriteAllText("C:\Users\15390\.trae-cn\work\.voice-reader\pending.txt", $c, [System.Text.Encoding]::UTF8)

4.2 命令行朗读

node "C:\Users\15390\.trae-cn\work\.voice-reader\voice-reader.mjs" "要朗读的文字"

4.3 直接写入朗读

$f = "C:\Users\15390\.trae-cn\work\.voice-reader\pending.txt"
[System.IO.File]::WriteAllText($f, "", [System.Text.Encoding]::UTF8)
$c = @"
[VOICE_READER_START:info]
要朗读的内容
[VOICE_READER_END]
"@
[System.IO.File]::WriteAllText($f, $c, [System.Text.Encoding]::UTF8)

4.4 停止朗读

node "C:\Users\15390\.trae-cn\work\.voice-reader\voice-reader.mjs" --stop

或写入 stop.flag：

[System.IO.File]::WriteAllText("C:\Users\15390\.trae-cn\work\.voice-reader\stop.flag", "STOP", [System.Text.Encoding]::UTF8)

4.5 查看状态

提示音类型

5.1 四种类型对比

类型标记开始提示音结束提示音使用场景
info[:info]800→1200Hz 升调600Hz 单音日常对话
success[:success]600→800→1200Hz 三阶升1200→600Hz 降调任务完成
error[:error]1000→600→400Hz 三阶降300Hz 低沉报错提醒
warning[:warning]800→500Hz 双音警示400Hz 单音重要提醒

系统架构

用户输入→ AI 处理→ 写入 pending.txt→ 监听器轮询→ 开始提示音→ SAPI 朗读→ 结束提示音→ 清空文件

6.1 架构详解

组件职责实现
AI 注入器在回复前后写入 pending.txtSKILL.md 定义
pending.txt共享文件，跨任务通信固定路径，所有任务可写
voice-watcher后台监听器，2 秒轮询检测Node.js + ES Module
voice-reader朗读引擎，解析标记并调用 SAPINode.js + PowerShell
lib.js公共模块，配置与工具函数提示音配置、文本清洗
SAPI 引擎Windows 原生 TTS，多音字准确ComObject SAPI.SpVoice

6.2 文本处理流程

原始文本
  → 去除代码块 ```...```
  → 去除行内代码 `...`
  → 去除加粗 **...**
  → 去除标题 # ...
  → 去除链接 [text](url)
  → 去除 URL
  → 去除列表标记 - * +
  → 合并多余空行
  → 超过 200 字自动截断
  → 写入 pending.txt

故障排查

问题 1：完全听不到声音

  1. 检查系统音量是否打开
  2. 确认监听器在运行：Get-CimInstance Win32_Process -Filter "Name='node.exe'" | Where-Object { $_.CommandLine -like '*voice-watcher*' }
  3. 直接测试：node voice-reader.mjs "测试朗读"
  4. 检查 pending.txt 是否有内容

问题 2：新任务无法调用

  1. 输入 Use Skill: voice-reader 显式调用
  2. SKILL.md 中路径使用全局路径 C:\Users\15390\.trae-cn\work\.voice-reader\，不依赖 workspace
  3. 确保 skill-config.json 中 voice-reader-injector 的 enabled: true
  4. 若仍失败，重启 Trae 后重试

问题 3：朗读声音过快

检查 lib.js 中的 SPEAK_RATE，当前设置为 0（默认语速）。调整为：-10 最慢 → +10 最快。

问题 4：朗读不完整

  • 内容超过 200 字自动截断，请分段写入
  • 代码块、路径、URL 会被自动过滤

问题 5：监听器突然退出

# 检查是否有僵尸 pending.txt
Get-Content "C:\Users\15390\.trae-cn\work\.voice-reader\pending.txt" -Encoding UTF8

# 重新启动
node "C:\Users\15390\.trae-cn\work\.voice-reader\voice-watcher.mjs"

问题 6：多音字读错

SAPI 原生引擎上下文感知能力强，绝大多数多音字读对。若个别词汇读错，建议在文本中手动补充读音标注（如"银行 yín háng"）。

配置选项

7.1 语速调节

修改 lib.js 中的 SPEAK_RATE：

export const SPEAK_RATE = 0;  // 当前：默认语速
// 可选范围：-10（最慢） ~ +10（最快）

7.2 音量调节

在 voice-reader.mjs 的 speak() 函数中，PowerShell 部分添加：

$voice.Volume = 80  // 0-100，默认 100

7.3 提示音自定义

修改 lib.js 中的 BEEP 对象。格式：频率Hz,持续时间ms，多段用 ; 分隔：

export const BEEP = {
    info: { start: "800,120;80;1200,120;150", end: "600,120" },
    success: { start: "600,100;80;800,100;80;1200,120;150", end: "1200,80;60;600,80" },
    error: { start: "1000,150;80;600,150;80;400,150;200", end: "300,120" },
    warning: { start: "800,200;100;500,200;150", end: "400,120" }
};

7.4 轮询间隔

修改 lib.js 中的 POLL_INTERVAL（毫秒）：

export const POLL_INTERVAL = 2000;  // 当前：2 秒

7.5 共享文件路径

修改 lib.js 中的 PENDING 路径，或修改 voice-watcher.mjs 导入的常量：

export const PENDING = "C:\\Users\\15390\\.trae-cn\\work\\.voice-reader\\pending.txt";

7.6 开机自启

  1. 按 Win + R，输入 shell:startup
  2. 创建 voice-reader.bat，内容：
@echo off
node "C:\Users\15390\.trae-cn\work\.voice-reader\voice-watcher.mjs"
